CV01 · 调声参数

关于

这个博客长什么样，用什么搭的，以及怎么把它改成你自己的。

这里写一段自我介绍。名字、在做什么、为什么开这个博客，三句话以内最好。下面这张表是站点自己的参数——它是给人看的，也是给未来的你看的。

建站方式

纯静态 HTML。没有框架、没有依赖、没有构建也能跑——双击 index.html 就能看。

内容源

content/posts.mjs 是唯一的内容源，运行 node tools/build.mjs 重新生成全部页面；也可以直接手改生成出来的 HTML。

目录

左边那排琴键和首页的卷帘是同一个东西：九个板块 = 九个音。低音在下（做题区doge 是 F#3，也是唯一一个黑键），越往上越轻。文章页顶部那条迷你卷帘会告诉你现在在哪一格。

每日一句

每一页顶上那句小字来自「胡盐乱雨集」。它以本地日期为种子选句，所以全站同一天显示同一句，过了零点自动换。句子写在 content/posts.mjs 的 excerpts 里。

配色

地是中性冷灰 #F5F8F8，墨是 #2D3033——阅读的重量交给灰度的差，不交给色相。两组标志色只用来强调：粉负责指认（链接、序号、音高名），青绿负责暗窗内部（音符块、读数）。「此刻」是画面上唯一会动的东西。

字体

读到的是思源宋体（系统回退），操作界面是无衬线，测量数字用随站自带的 Big Shoulders。三个角色，各干各的事。

素材

全部视觉都是 CSS 与 SVG 现画的，没有引入任何插画素材。

钢琴声

默认关闭，顶栏「开启音效」打开后：点轨道名会先响一声再切板块，卷帘上的音符可以掠过试听。没有采样文件时用 WebAudio 现场合成；想换成真钢琴，把文件放进 assets/audio/，按音高命名（a5.mp3、fs3.mp3…），缺哪个补哪个。

上传

双击 start.cmd 起一个零依赖的 Node 服务，右下角就多出三颗悬浮球：音乐盒（进页面自动播放，点球选歌，支持 mp3 / m4a）、发说说（文字、图片、视频、表情包，能发到任意板块或子板块）、新建板块（给新板块挑一个还没被占用的音高，它就接进卷帘）。文件落在 media/，记录落在 data/*.json。第一次上传要输一次口令，口令印在启动服务的那个终端里。

说说流

所有板块上传的内容汇总在 说说 页，按时间倒序；每个板块页和文章页的底下也各有一条。删除按钮只对输入过口令的浏览器显示。

联系

改成你的邮箱、RSS 或社交账号。别留着占位符。

配色

6 个职务

地　中性冷灰，整站的地面（12.4:1）#F5F8F8
墨　正文与结构线（12.4:1）#2D3033
签·地面　链接与序号（4.5:1）#D81B7A
签·暗窗　音符块与读数，只在暗窗上（8.0:1）#39C5BB
暗窗　全站唯一的深色区域#1A1C1E
此刻　播放头、焦点环、进度#FF3399

改配色只需动 assets/css/tokens.css：里面是完整的两套（日间调声 / 夜间调声），夜间不是在日间上做反相。青绿 #39C5BB 对浅地面只有 2.0:1，所以它只出现在暗窗里；粉的深色档比来源调色板压深了一格，为的是正文过 AA。
