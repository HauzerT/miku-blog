CV01 · 调声参数

关于

这个博客长什么样，用什么搭的，以及怎么把它改成你自己的。

这里写一段自我介绍。名字、在做什么、为什么开这个博客，三句话以内最好。下面这张表是站点自己的参数——它是给人看的，也是给未来的你看的。

建站方式

纯静态 HTML。没有框架、没有依赖、没有构建也能跑——双击 index.html 就能看。

内容源

content/posts.mjs 是唯一的内容源，运行 node tools/build.mjs 重新生成全部页面；也可以直接手改生成出来的 HTML。

目录

左边那排琴键和首页的卷帘是同一个东西：九个板块 = 九个音。低音在下（做题区doge 是 F#3，也是唯一一个黑键），越往上越轻。文章页顶部那条迷你卷帘会告诉你现在在哪一格。

每日一句

每一页顶上那句小字来自「胡盐乱雨集」。它以本地日期为种子选句，所以全站同一天显示同一句，过了零点自动换。句子写在 content/posts.mjs 的 excerpts 里。

配色

颜色不写在 CSS 里：content/palette.mjs 是全站唯一写着色值的地方，node tools/tokens.mjs 校验对比度并生成 assets/css/palette.css。颜色在这里是职务不是气氛——地承担全部阅读重量（重量交给灰度的差，不交给色相），墨写正文，签只用来指认被选中的东西，示只表示「此刻」，是画面上唯一会动的东西。换一整套配色 = 改那个文件里的一行轮次。

字体

读到的是思源宋体（系统回退），操作界面是无衬线，测量数字用随站自带的 Big Shoulders。三个角色，各干各的事。

素材

全部视觉都是 CSS 与 SVG 现画的，没有引入任何插画素材。

钢琴声

默认关闭，顶栏「开启音效」打开后：点轨道名会先响一声再切板块，卷帘上的音符可以掠过试听。没有采样文件时用 WebAudio 现场合成；想换成真钢琴，把文件放进 assets/audio/，按音高命名（a5.mp3、fs3.mp3…），缺哪个补哪个。

上传

双击 start.cmd 起一个零依赖的 Node 服务（顺手把云村那个小服务也一起拉起来，kumura.html 打开就能扫码），右下角就多出两颗悬浮球。音乐盒是公开的：谁都能开、能听、能选歌、能把某一首设成「进页面自动播的那一首」。站长工具箱要口令，里面三件事：新建板块 / 子板块、上传音乐盒的音乐、快速写一篇博客。文件落在 media/，记录落在 data/*.json。第一次写要输一次口令，口令印在启动服务的那个终端里（也可以改 data/settings.json 里的 passphrase）；想关掉就双击 stop.cmd，它自己按进程找，不用记端口。

写文章

站长工具箱里的「快速写一篇博客」会跳到一个独立编辑页 editor.html：标题、板块、日期、阅读分钟、短标签、一句话简介，正文用 Markdown 子集写（## 小标题、- 列表、> 引用、反引号代码块，整块 HTML 原样放行），图片 / 视频 / 音乐拖进正文框就能传。文章存在 data/articles.json，页面由服务实时渲染，同时并进板块页的文章列表、归档、首页索引与卷帘——跟新建板块一样，建完立刻看得见。

听歌

歌是跨页面接着放的。站内跳转由 assets/js/nav.js 接管：取回目标页之后只换正文、标题和高亮，右下角那根 <audio> 从头到尾没被销毁，所以切板块、翻文章、按后退都不会从头再来。代价是页面切换不再是整页刷新；file:// 下没有 fetch，会自动退回普通跳转；云村页自带扫码轮询与自己的播放器，进出它仍走整页。

联系

改成你的邮箱、RSS 或社交账号。别留着占位符。

配色

6 个职务

地　整站的地面，阅读的重量都在它身上--paper
墨　正文与结构线--ink
签·地面　被指认的东西：链接、序号、音高名--miku-deep
签·暗窗　音符块与读数--miku
暗窗　全站唯一的深色区域--display
此刻　播放头、焦点环、进度--cuer

改配色只需动 content/palette.mjs——全站唯一写着色值的地方，然后跑一次 node tools/tokens.mjs：它会重算每对前景/背景的对比度，不够 AA 就拒绝生成，并把实测值写进 assets/css/palette.css 顶上那张表。上面这些色块与十六进制都跟着它走，不写死在这一页里。
