CV01 · 调声参数

关于

这个博客长什么样，用什么搭的，以及怎么把它改成你自己的。

这里写一段自我介绍。名字、在做什么、为什么开这个博客，三句话以内最好。下面这张表是站点自己的参数——它是给人看的，也是给未来的你看的。

建站方式

以纯静态 HTML 为底：没有框架、没有构建，双击 index.html 就能看（悬浮球自动隐身）。第三方只随站自带两个本地库——marked 排 Markdown、KaTeX 排公式，不联网、不 CDN，file:// 照跑。跑起服务（双击 start.cmd，零依赖的 Node）才有的另一半：门厅、编辑、上传、音乐盒、云村。

内容源

两个源，各管一半。手写的一半：content/posts.mjs（板块、文章、每日一句），node tools/build.mjs 重新生成全部页面，生成出来的 HTML 也可以直接手改。界面写的一半：编辑页写的文章、工具箱建的板块落在 data/*.json——服务在线时页面由它实时渲染，新建板块的定义构建时也会并进静态页。

门厅

服务跑着的时候，站点每一页都得先过 login.html：访客（粉键）按一下就进，盖三十天的章；站长（黑键）要口令。口令第一次启动自动生成，是一串 32 位的随机字符，印在启动服务的终端里——tools/set-passphrase.mjs 换一条，tools/owner.cmd 一键进门（起服务、口令进剪贴板、打开门厅）。口令错多了会被限速，越错等得越久。不想过这道门，data/settings.json 里写 "gate": false。

目录

左边那排琴键和首页的卷帘是同一个东西：九个板块 = 九个音。低音在下（做题区doge 是 F#3，也是唯一一个黑键），越往上越轻。首页的卷帘是一条时间轴：音符按写作日期往右接，越往右越新，同一个月的几篇一篇挨一篇排在一起（顶部月份牌子后面带着篇数），没发文的日子不留空白；文章页顶部那条迷你卷帘会告诉你现在在哪一格。

每日一句

每一页顶上那句小字来自「胡盐乱雨集」。它以本地日期为种子选句，所以全站同一天显示同一句，过了零点自动换。句子写在 content/posts.mjs 的 excerpts 里。

配色

颜色不写在 CSS 里：content/palette.mjs 是全站唯一写着色值的地方，node tools/tokens.mjs 校验对比度并生成 assets/css/palette.css。颜色在这里是职务不是气氛——地承担全部阅读重量（重量交给灰度的差，不交给色相），墨写正文，签只用来指认被选中的东西，示只表示「此刻」，是画面上唯一会动的东西。换一整套配色 = 改那个文件里的一行轮次。

字体

读到的是思源宋体（系统回退），操作界面是无衬线，测量数字用随站自带的 Big Shoulders。三个角色，各干各的事。

素材

全部视觉都是 CSS 与 SVG 现画的，没有引入任何插画素材。

钢琴声

默认关闭，顶栏「开启音效」打开后：点轨道名会先响一声再切板块，卷帘上的音符可以掠过试听。原生九个音（A3–A5，含黑键 F#3）已经放好真钢琴的实录采样（VSCO 2 Community Edition，CC0，按音高命名躺在 assets/audio/）；没采样文件的音高——比如新建板块挑的 B5、C6——由 WebAudio 现场合成顶替，缺哪个补哪个。

上传

双击 start.cmd 起一个零依赖的 Node 服务（顺手把云村那个小服务也一起拉起来，kumura.html 打开就能扫码），右下角就多出两颗悬浮球。音乐盒是公开的：谁都能开、能听、能选歌、能把某一首设成「进页面自动播的那一首」。站长工具箱要口令（就是门厅那把），里面三件事：新建板块 / 子板块、上传音乐盒的音乐、快速写一篇博客；音乐盒里换歌、改名、删歌也归它管。文件落在 media/，记录落在 data/*.json。想关掉就双击 stop.cmd，它自己按进程找，不用记端口。

写文章

站长工具箱里的「快速写一篇博客」会跳到独立编辑页 editor.html：标题、板块 / 子板块、日期、阅读分钟、短标签、一句话简介，正文用 Markdown（GFM 全量）写——表格、任务列表、删除线都在，公式用 $行内$ 和 $$…$$（KaTeX 在服务端排好版），emoji 直接打或写 :smile: 这样的短代码。图片 / 视频 / 音乐拖进正文框、点按钮选、或 Ctrl+V 粘截图都能传，传完自动塞到光标处，右栏实时预览。文章存在 data/articles.json，页面由服务实时渲染，同时并进板块页的文章列表、归档、首页索引与卷帘——建完立刻看得见。

改字

不用重新生成页面也能改字。服务在线且有口令的浏览器，命令栏右侧多一颗「全局编辑」：一按整站进编辑模式，虚线框里的文字点一下就直接改——板块名、简介、导语、文章标题与正文、轨道栏与首页索引，空的简介 / 导语还能就地「＋ 新建」，Esc 退出。破坏性的事（改名 / 撤下）仍住在站长右键菜单里。界面上改原生文章不动源文件，改动记进 data/overrides.json 覆盖层。

听歌

歌是跨页面接着放的。站内跳转由 assets/js/nav.js 接管：取回目标页之后只换正文、标题和高亮，右下角那根 <audio> 从头到尾没被销毁，所以切板块、翻文章、按后退都不会从头再来。file:// 下没有 fetch，会自动退回普通跳转。云村（kumura.html）扫码登录网易云：账号卡、我创建的歌单架、每天 6:00 更新的每日推荐、按加入时间倒序的红心歌单，点歌就在本页出声；它自带扫码轮询与自己的播放器，进出它仍走整页。

联系

改成你的邮箱、RSS 或社交账号。别留着占位符。

配色

6 个职务

地　整站的地面，阅读的重量都在它身上--paper
墨　正文与结构线--ink
签·地面　被指认的东西：链接、序号、音高名--miku-deep
签·暗窗　音符块与读数--miku
暗窗　全站唯一的深色区域--display
此刻　播放头、焦点环、进度--cuer

改配色只需动 content/palette.mjs——全站唯一写着色值的地方，然后跑一次 node tools/tokens.mjs：它会重算每对前景/背景的对比度，不够 AA 就拒绝生成，并把实测值写进 assets/css/palette.css 顶上那张表。上面这些色块与十六进制都跟着它走，不写死在这一页里。
