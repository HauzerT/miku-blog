# assets/audio/ · 采样放这里（可选）

**不放任何文件，站点的钢琴声也是完整可用的**——没有采样时，浏览器会用 WebAudio
现场合成一个柔和的电钢琴音色，**任何音高都算得出来**（十二平均律，A4 = 440Hz），
不需要下载、不需要联网。

现在原生九个板块的音已经是真钢琴了（VSCO2 社区版实录采样，来源与授权见文末）。
下面列的仍然是命名规矩本身——想补别的音、或者换成你自己的音源，照着来就行：

想往目录里放文件，按**音高**命名：

```
assets/audio/
  a5.mp3     二次生命
  fs5.mp3    恰同学少年
  d5.mp3     胡盐乱雨集
  b4.mp3     千千千世界
  g4.mp3     生活在云上
  e4.mp3     剪剪又辑辑
  c4.mp3     整点薯条
  a3.mp3     网上囚徒
  fs3.mp3    做题区doge（黑键）
  b5.mp3     用界面新建的板块挑的音也照这个规矩来
```

规则只有两条：

1. **文件名就是音高**，小写，`#` 写成 `s`（F#3 → `fs3`）。支持 `.mp3` / `.wav` / `.ogg`，
   按这个顺序找，找到哪个用哪个。原生九个音之外的音高（新建板块挑的 B5、C6…）一样认。
2. **可以只放一部分**。缺哪个音，哪个音就用合成音色顶替——混着用也没问题。

建议：单个文件压到 100 KB 以内、控制在 1–2 秒（切模块时的音符只响 190 毫秒就会跳页，
太长会被截断）。想让它响久一点，改 `assets/js/audio.js` 顶部的 `SWITCH_DELAY`。

音效默认是**关闭**的，顶栏的「开启音效」按钮打开后才会发声，选择记在 localStorage 里。
