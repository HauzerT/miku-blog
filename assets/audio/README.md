# assets/audio/ · 采样放这里（可选）

**不放任何文件，站点的钢琴声也是完整可用的**——没有采样时，浏览器会用 WebAudio
现场合成一个柔和的电钢琴音色，**任何音高都算得出来**（十二平均律，A4 = 440Hz），
不需要下载、不需要联网。

现在原生九个板块的音已经是真钢琴了（VSCO2 社区版实录采样，来源与授权见文末）。
下面列的仍然是命名规矩本身——想补别的音、或者换成你自己的音源，照着来就行：

想往目录里放文件，按**音高**命名：

```
assets/audio/
  a5.mp3     二次生命
  fs5.mp3    恰同学少年
  d5.mp3     胡盐乱雨集
  b4.mp3     千千千世界
  g4.mp3     生活在云上
  e4.mp3     剪剪又辑辑
  c4.mp3     整点薯条
  a3.mp3     网上囚徒
  fs3.mp3    做题区doge（黑键）
  b5.mp3     用界面新建的板块挑的音也照这个规矩来
```

规则只有两条：

1. **文件名就是音高**，小写，`#` 写成 `s`（F#3 → `fs3`）。支持 `.mp3` / `.wav` / `.ogg`，
   按这个顺序找，找到哪个用哪个。原生九个音之外的音高（新建板块挑的 B5、C6…）一样认。
2. **可以只放一部分**。缺哪个音，哪个音就用合成音色顶替——混着用也没问题。

建议：**想让它响久一点、或者文件大一点，都没关系**——播放走的是 WebAudio
（`composables/sound-engine.mjs`）：采样一次拉下来解码成 AudioBuffer 缓存住，
起音与收尾都有斜坡，切模块时在 `hold + release`（默认 0.22s + 0.48s）处淡出，
不会硬切、也不会「啪」。每个采样在加载时会**归一化到同一个峰值**，所以录得响的
和录得轻的听起来一样响，不用自己压。

仍然值得做的一件事：**手机上第一次点进来的流量**。开着音效时站点会先把这一页
看得到的音拉下来（最多 12 个），九个原生音合计约 1.5 MB；想省流量就按老建议
压到 100 KB 以内、1–2 秒——听感上几乎没有损失（切模块那一声只响 0.7 秒）。

音效默认是**关闭**的，顶栏的「开启音效」按钮打开后才会发声，选择记在 localStorage 里。
