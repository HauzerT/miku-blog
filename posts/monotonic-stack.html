单调栈的三个不变式

2025.03.14 · 做题区doge · 9 分钟

单调栈不难写，难的是写完之后能说出它为什么对。我把它压成三个不变式，之后每次手抖都能靠它们救回来。

一、栈内单调

栈里存的永远是“还没找到答案”的下标，它们的值从栈底到栈顶保持单调。一个新的元素进来之前，先把破坏单调性的那些弹掉——而破坏单调性的那些元素，它们的答案就是当前这个新元素。

二、弹即定答

一个下标被弹出的那一刻，它的答案就确定了，之后不会再改。所以每个下标最多进出栈各一次，总复杂度 O(n)。这是我最容易忘的一条：忘了它，就会在弹出时犹豫“要不要再比较一次”，然后写出一个看着对、跑起来错的版本。

三、留下来的没有答案

扫描结束后仍然留在栈里的下标，说明它们右边不存在更大的（或更小的）元素。按题意填默认值，别让数组里留着 undefined。

写的时候要区分的三件事

  • 存值还是存下标：只要需要算宽度、算距离，就必须存下标。
  • 比较用 > 还是 >=：相等元素谁先弹，直接决定左右边界的定义。
  • 弹出时结算，还是入栈时结算：两者都可行，但不能混用。
function nextGreater(nums) {
  const res = new Array(nums.length).fill(-1);
  const stack = [];              // 存下标，保持 nums[stack[i]] 单调递减
  for (let i = 0; i < nums.length; i++) {
    while (stack.length && nums[stack[stack.length - 1]] < nums[i]) {
      res[stack.pop()] = nums[i]; // 不变式二：弹即定答
    }
    stack.push(i);
  }
  return res;                     // 不变式三：留在栈里的保持 -1
}

检验方法很土但有效：随手画一排柱子，手动跑一遍，数一数每个下标是不是只被弹出过一次。数不对，就是不变式二没守住。
