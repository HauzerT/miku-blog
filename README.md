# 初音ミク CV01 · 个人博客骨架

一个用**钢琴卷帘当目录**的静态个人博客。零依赖、零构建也能跑：双击 `index.html` 就能看。
主题是一条工程界面式的人声合成器：九个板块 = 九条轨道 = 一个和弦的九个音。
再双击一次 `start.cmd`，它就多出一套**上传系统**：音乐盒、发说说、新建板块。

```
A5  二次生命        二次元
F#5 恰同学少年      同学回忆录
D5  胡盐乱雨集      随笔
B4  千千千世界      旅游
G4  生活在云上      在云村的音乐之旅
E4  剪剪又辑辑      剪辑
C4  整点薯条        美食
A3  网上囚徒        cyberWorld
F#3 做题区doge      EE学生的自我迭代
```

越往下越重，越往上越轻。音高名取代了 01/02/03 序号——**编号在这里携带信息**，不是装饰。
这九个音（F#3 – A5）堆叠三度，构成一个加了延伸音的和弦。懂乐理的人会心一笑，不懂的人只觉得这条上升的线好看。

## 上传系统（本机跑，数据落在自己硬盘上）

**启动**：双击 `start.cmd`（或 `node server/server.mjs`），开 `http://127.0.0.1:4321/`。
终端会打印一串**上传口令**，第一次上传时输一次，之后这个浏览器就记住了。
关掉窗口就是停止服务；端口可以跟在命令后面换（`node server/server.mjs 8080`）。

右下角因此多出三颗悬浮球：

| 球 | 能干什么 |
|---|---|
| **音乐盒** | 进页面**自动播放**；点球展开选歌面板（播放/上一首/下一首/单曲循环/随机、拖进度、调音量）；拖 mp3 / m4a 进去或点「选择文件」上传；每首还能**设默认**（哪一首是每次进页面先放的那一首）、**换**（用本机另一个文件原地替换，名字位置都不动）、改名、删除 |
| **发说说** | 选板块（有子板块就再选一层）→ 写字（`Ctrl+V` 粘截图、拖文件进来都行）→ 加图片 / 视频 / 表情包，一条可带多个附件；发出去立刻出现在当前列表 |
| **新建板块** | 给新板块起名、挑一个**还没被占用的音高**（默认帮你挑空着的那个）、写定义与导语；也能给任何板块加子板块、删子板块 |

**自动播放这件事**：浏览器不允许「没有任何交互就出声」，所以流程是——进页面先试一次，
被拦下就在音乐球上亮一颗樱粉色的灯，此后**第一次点击、滚动或按键**就接着放。
不想听就点开面板按暂停；曲库空了自然也不会响。

**东西放在哪**：文件进 `media/`（`music/` `images/` `videos/` `stickers/`），
记录进 `data/`（`sections.json` `posts.json` `music.json` `settings.json`）。
把 mp3 直接拖进 `media/music/` 也会被认出来，刷新页面即可。
`data/` 与 `media/` 默认写在 `.gitignore` 里——自己的东西不一定想进仓库。

**上限**：单个上传请求 256MB（一次上传的所有文件加起来算）。图片在浏览器里会先缩到长边 1920 再传，
手机直出照片通常掉到几百 KB，所以瓶颈一般在视频。要更大的，
改 `server/lib/multipart.js` 顶部的 `DEFAULT_LIMIT`；真正大的场合应该换成流式写盘。

**没有服务也能看**：`file://` 双击 `index.html`，或把整站丢到静态托管上——悬浮球会自动隐身，
页面与以前完全一样，说说区显示的是上次生成时内联进去的那几条。

**自检**：改了这一块之后，两个脚本可以把「看得见的」和「点得动的」都过一遍：

```bash
node server/server.mjs 4321      # 另开一个窗口把它跑着
node tools/dom-check.mjs         # 每类页面：控制台有没有报错、面板开不开、截图进 .check/
node tools/upload-check.mjs      # 从文件选择器真实上传图片与音乐，跑完自己清理干净
```

## 钢琴声（可选，默认关闭）

顶栏的「开启音效」打开后：**点轨道名 / 点卷帘的轨道头 —— 先响一声，再切模块**；
指针掠过音符块、或用方向键在卷帘上走，会试听那个音。关闭状态下零拦截、零延迟。

**要不要自己导入文件？不必。** 没有采样时，浏览器用 WebAudio 现场合成一个柔和的电钢琴音色，
九个音一个不少，不联网、不下载。想换成真钢琴（或你自己的音源），把文件放进 `assets/audio/`，
**按音高命名**即可：

```
assets/audio/a5.mp3    fs5.mp3    d5.mp3    b4.mp3    g4.mp3
            e4.mp3    c4.mp3     a3.mp3    fs3.mp3
```

`#` 写成 `s`（F#3 → `fs3`），支持 mp3 / wav / ogg。**可以只放一部分**——缺哪个音，
哪个音就用合成音色顶替，混着用没问题。详细规则见 `assets/audio/README.md`。

音量、切换前的停留时长都在 `assets/js/audio.js` 顶部（`MASTER` / `SWITCH_DELAY`）。
音效开关记在 localStorage 里，不会每次访问都重开。

## 云村（扫码登录网易云，可选）

`kumura.html` 是「生活在云上」那条轨道的落地页：**扫码登录网易云音乐 → 看账号信息 → 翻红心歌单**。

它需要一个小服务。原因有两个，都是硬的，绕不过去：

1. 网易云的接口要加密（AES + RSA），纯前端做等于把算法和密钥摊在明面上；
2. 网易不下发 CORS 头，浏览器会直接拦掉跨域请求。

所以本站的静态页面照旧，只有这一页会去问本机的一个小服务：

```bash
node tools/ncm-server.mjs          # 起服务，默认 http://127.0.0.1:3170
node tools/ncm-server.mjs --selftest   # 只做自检，不占端口
```

没起服务也能打开这一页——它会明说「小服务没在跑」，并把这行命令写给你，而不是白屏。

**它是怎么工作的**

浏览器只跟自己的小服务说话，小服务再带着加密参数去问网易：

```
kumura.html  →  /api/login/qr/key    →  小服务 → 网易
             ←  二维码内容（一段 URL）
   （浏览器用 assets/js/qr.js 自己把这段 URL 画成二维码）
             →  /api/login/qr/check   →  轮询扫码状态 801/802/803
             ←  803 时小服务收下 cookie，存进 .ncm-session.json
             →  /api/account         →  昵称、头像、等级、关注、粉丝、云村年龄
             →  /api/liked           →  红心歌单分页
```

**几个刻意的选择**

- **二维码是本地画的。** `assets/js/qr.js` 是个约 300 行的二维码编码器（字节模式、纠错等级 L、
  固定掩码 0），只做扫码登录需要的那个子集。为了一张二维码去引一个第三方库，
  等于把本站「零依赖、`file://` 也能跑」这条底线拆掉。
  正确性由 `node tools/check-qr.mjs` 用 OpenCV 反过来实扫验证（含 2 像素/模块的极端密度）。
- **登录凭证不进浏览器。** cookie 只写在小服务旁边的 `.ncm-session.json`（已加进 `.gitignore`），
  页面这边不碰 localStorage，也不接触任何密钥。
- **走 eapi，不走 weapi。** 这是实测结论：网易已经把 `weapi` 通道关掉了（请求返回 HTTP 200 但响应体是空的），
  `eapi` 仍然正常。`tools/ncm-server.mjs` 因此统一用 eapi。
- **账号和红心歌单都只读。** 小服务不提供任何写操作（不收藏、不取消红心、不改歌单）。
  要看某个账号的红心歌单，前提是你用那个账号扫了码。

**可调项**都在 `assets/js/music.config.js`（服务地址、每页条数、轮询间隔、二维码有效期）。
把整站放到线上时，把 `service` 改成你部署小服务的地址即可。

**播放**（红心歌单里每首歌右边的圆钮）

点一下就在本页出声，底部升起一条播放条：封面、曲名、进度、音量、上一首/下一首。
队列就是"当前已经读出来的这些"，播到底从头循环。

音频**直连网易的 CDN**，不经小服务中转——那些地址带 `Access-Control-Allow-Origin: *`，
浏览器自己就能播；小服务只负责把地址取回来（`/api/song/url`）。地址约 20 分钟过期，
所以服务端做了 12 分钟缓存，翻来覆去点同一首不会反复打网易。

三种情况都有说法，不会静默失败：

| 情况 | 页面上的表现 |
|---|---|
| 拿不到地址（下架 / 版权 / 需付费） | 播放条写明"拿不到播放地址"，那一行也不给播放键 |
| 地址过期了 | 提示"再点一次就会重新取" |
| 能取到地址但浏览器拦了自动播放 | 提示"点一下播放键"——这是浏览器策略，不是坏了 |

音质按 `exhigh → higher → standard` 逐级降级；有黑胶 VIP 的账号实测能拿到 320kbps。

改动这一页之后，可以跑一遍浏览器自检（会开无头 Chrome，把四种状态都过一遍：

```bash
node tools/check-kumura.mjs        # 结果截图在 .check/
```

「已登录」和「二维码作废」那两种是靠注入脚本 + 替换 `fetch` 测的——
不碰真账号，也不用为了测试而登录。

## 改内容

**路线 A（推荐）**：编辑 `content/posts.mjs`，然后

```bash
node tools/build.mjs
```

它重新生成 `index.html` / `archive.html` / `sections/*.html` / `posts/*.html`。
每篇文章的 `min`（阅读分钟数）决定它在卷帘上的**宽度**，`short`（≤4 字）是音符块上的标签。

**路线 B**：直接改生成出来的 HTML。它们就是普通静态文件，没有运行时依赖，改完即生效。

新增板块：点右下角那颗悬浮球，用界面建（记录进 `data/sections.json`，页面由服务运行时渲染，
不用重新跑生成器）；或者走老的静态路线——在 `content/posts.mjs` 的 `tracks` 里加一项，并给
`tools/build.mjs` 的 `RHYTHMS` 补一条节奏（音符的 x 位置与宽度百分比，手工排的，
决定整条卷帘的呼吸）。两条路的板块会合并显示在轨道栏和首页索引里。
`assets/js/site.js` 与 CSS 会自动适配任意数量的轨道。

## 页顶「每日一句」

每一页的最上面有一行小字，取自「胡盐乱雨集」。它**不是**随机刷新——以本地日期做种子，
所以同一天里全站、所有刷新都是同一句，过了本地零点自动换下一句。

句子写在 `content/posts.mjs` 的 `excerpts` 数组里（`tools/build.mjs` 会把它编译成
`assets/js/excerpts.js`）。想加就加，想换就换，条数不限。关掉的办法：删掉 `excerpts` 数组，
或把 `.epigraph` 从页面上删掉。

## 发布

整站是纯静态的，丢到任何静态托管即可（GitHub Pages / Cloudflare Pages / 自己的机器）。
`file://` 直接打开也完整可用——字体在本地，没有任何外部请求。

**唯一的例外是 `kumura.html`。** 它要问本机的小服务，所以：
- 只在你自己机器上跑：`node tools/ncm-server.mjs` 开着即可，页面照常；
- 想放到线上：把小服务部署到一个地址，改 `assets/js/music.config.js` 里的 `service`。
  但请注意——**那个地址上就存着你的网易云登录态**，别把它暴露在公网上。
  换句话说：云村这一页适合留给自己，不适合挂在公开博客上给所有人点。

**上传系统同理，而且更彻底**：音乐盒、发说说、新建板块这三件事都要写文件，
`file://` 和静态托管上做不到——它们只在 `node server/server.mjs` 跑着的时候出现。
不跑服务，整站就是原来那个纯静态博客，一个字节都没变。

## 设计系统速查

**颜色即语法**（改配色只需动 `assets/css/tokens.css`）：

| 变量 | 亮色 | 暗色 | 职务 |
|---|---|---|---|
| `--paper` | `#F5F8F8` | `#1A1C1E` | 地：中性冷灰，承担全部阅读重量（正文 12.4:1） |
| `--ink` | `#2D3033` | `#E6EBEF` | 墨：正文与结构线 |
| `--miku-deep` | `#D81B7A` | `#FF69B4` | 签·地面态：链接、序号、音高名（4.5:1 / 6.4:1） |
| `--miku` | `#39C5BB` | `#39C5BB` | 签·暗窗态：音符块、读数（**只**在暗窗上，8.0:1） |
| `--display` | `#1A1C1E` | `#0C0E10` | 暗窗：全站唯一的深色区域（卷帘、页脚、视频屏） |
| `--card` | `#FFFFFF` | `#2D3033` | 面：浮起来的面板（工作台 / 发说说 / 云村） |
| `--cuer` | `#FF3399` | `#FF69B4` | 此刻：播放头、焦点环、进度 |

两组标志色各有分工：**粉**负责指认（链接、序号、音高名），**青绿**负责暗窗内部
（音符块、读数）。青绿 `#39C5BB` 对浅地面只有 2.0:1，所以它不出现在地面上——
这条纪律是物理规定的，不是风格规定的。粉的深色档 `#D81B7A` 比来源调色板的
`#E12885` 压深了一格：后者对 `#F5F8F8` 只有 4.06:1，差一点到 AA。

「此刻」用的是粉，不是琥珀：琥珀对旧的青底只有 1.05:1（那条焦点环其实一直是隐形的），
换到中性地面也只有 1.90:1。用 `#FF3399` 之后，焦点环对地面 3.2:1、播放头对暗窗 5.0:1，
两个场景才都真的看得见。

**字体三个角色**：思源宋体（读）/ 系统无衬线（操作）/ Big Shoulders（测量）。
等宽只用于代码，不用做标签。暗色主题（"夜间调声"）是另配的一套，不是反相。

**动效**：全站只有一次编排——载入时樱粉播放头扫过卷帘 2.2 秒，经过的音符依次点亮。
`prefers-reduced-motion: reduce` 下不扫，音符一次性呈现。

**无障碍**：卷帘支持 `←` `→`（同轨内沿时间轴）、`↑` `↓`（换轨）、`Home` / `End`；
所有可交互元素有 `:focus-visible` 樱粉描边；正文对比度过 AA（实测 12.4:1）。

## 手机（≤900px）

窄屏不是把桌面版压扁，是换一套读法：

- **命令栏在手机上折成两行**：顶级页面涨到五个（首页/说说/云村/归档/关于）之后，
  「铭牌 + 五个导航 + 两个开关」一行放不下了——320px 下光算宽度就差 70px。
  所以 ≤480px 时上行放铭牌与两个开关、下行五个导航平分整宽（每格约 57×44，
  比挤在一行里的小字好点得多）；481px 以上仍是单行。`--bar` 跟着变成
  `calc(5.5rem + 1px)`，轨道栏的粘顶位置才不会错位。
- **轨道栏留在顶上**：九个音从左侧竖排改成顶部横排，并继续粘在命令栏下面——
  读长文时随手就能换板块，不必滚回顶部。（单列下 `.shell` 从 grid 换成 block：
  grid 单列时轨道栏独占一行、行高等于自身，sticky 会退化成普通元素。）
- **卷帘留给手指**：轨道高 36px、音符块 25px，音符下面还垫了一层透明的可点区域，
  实际能点到约一格轨道那么高。播放头那 78% 的空盒子由 `.roll__field` 裁掉——
  否则手机上能一直往右滑进一片空白，桌面端还会平白多出一根横向滚动条。
- **「可以左右滑动」只在真能滑的时候出现**：`site.js` 量过 `scrollWidth` 才加 `.is-scrollable`。
  宽一点的手机上卷帘并不需要滑动，那就不说这句。
- **悬浮球不会吃掉页脚**：三个球是 `position: fixed` 的，视口右下那一条永远被压着，
  而页脚正好落在里面——手机上滚到底时版权两行原本会被球盖住。现在页脚留出了这条通道
  （球高 ×3 + 留白，写在 `studio.css` 里跟着球的实际尺寸走），滚到底页脚从球上面经过。
- **触摸的规矩**：`touch-action: manipulation` 去掉双击缩放那 300ms 的等待，点击高亮换成樱粉色；
  偏小的可点区域用透明 `::after` 或行内 `padding-block` 垫到 36–48px（视觉一点不动）；
  `@media (hover: none)` 里把只在指针下才该出现的悬停状态撤掉（手指点过之后 `:hover` 会一直粘着）。
- **刘海与圆角**：`viewport-fit=cover` + `env(safe-area-inset-*)`，横屏时正文不会钻进圆角；
  `theme-color` 跟着主题走，地址栏不留一条白带。这两样在 `server/lib/shell.mjs` 的 `head()`
  里统一发出——**`about.html` 是手写的、不走生成器**，改 head 时要一起改，否则它会悄悄掉队。
- **横屏手机**（高 ≤480px）：命令栏、hero、轨道各收一档，别让标题把正文挤出首屏
  （只在命令栏还是单行时才压矮它，480px 宽的横屏机走的是两行布局）。
- **正文**：代码块与表格在窄屏自己滚，行内代码允许断行；行距 1.9、字号 17px 不动——
  手机上一行 30 来个字，正好。

## 已知取舍

- 中文衬线走系统字体（Noto Serif SC / 宋体），不同机器渲染有细微差异——这是零构建的代价。
  想完全一致就把思源宋体的子集一起打包进 `assets/fonts/`。
- 窄屏上卷帘仍要横向滑动：九条轨道无法在手机上同时铺开。轨道名固定在左侧，
  320px 的机器上大约看得到三条轨道的三分之二——这是承认真实约束，不是没适配。
- 悬浮球固定在右下，手机上会压住正文最右侧约 58px（首页那条卷帘的右端也在其中）。
  这是悬浮球的固有代价；真嫌挡，可以让它在卷帘进入视口时淡出，或者手机上改成横排贴底。
- 中性地面比满屏饱和青好读得多（正文 12.4:1），代价是初音的标志青从「整站的地面」退到了
  暗窗内部——它现在只出现在卷帘、页脚、代码块、视频屏里。要找回满屏青，改 `--paper` 一个值即可。
- `design/keyvisual.html` 那张观测图海报仍是旧配色（青底）。它是独立的作品视图，没有跟着换；
  要一起换就得重新导出 PNG / PDF。
- 没有搜索、没有 RSS、没有评论。想加就加，别让骨架替你决定。
